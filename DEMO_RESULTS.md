# Observed demo checkpoint — November 16, 2026

This records an actual Cognee Cloud run, not an illustrative result.

## Task

Research potential teaming partners for a hypothetical small cybersecurity contractor investigating DHS identity-and-access-management work. Connect historical awards, agency guidance and company capabilities, and identify gaps before recommending a next step.

The shared source collection contained 25 historical awards, CISA zero-trust guidance, two company capability excerpts, and the current internal brief.

## What ran

- Opportunity analyst, partner researcher and evidence reviewer each produced a provider-backed report in a distinct Cloud session.
- Their actual execution traces were stored through Cognee's typed memory API.
- The partner retrieved the opportunity analyst's recorded trace; the reviewer retrieved earlier agents' traces.
- The reviewer proposed a reusable lesson separating capability claims, historical award scope and present teaming availability.
- That guidance was accepted through the app and submitted as a real reviewer-session turn.
- Native `improve()` consolidated the three research sessions.
- A fresh partner session received the original question/profile and retrieved permanent memory. The accepted feedback was not copied into its prompt.

## Native improvement results

| Stage | Observed result |
| --- | --- |
| Persist session Q&A | Completed; 3 sessions |
| Persist agent traces | Completed; 3 sessions / 3 windows |
| Extract agent context | Completed; 3 lessons, 0 sessions failed |
| Distill sessions | Completed; 4 documents, 2 sessions completed, 0 sessions failed |
| Update user preferences | Completed; 1 turn applied |
| Global context index | Completed |
| Feedback weights, truth subspace, conflict review | Skipped in this run |

**Fresh-session verification:** all four newly retrieved lesson excerpts were also present in the fresh agent's retrieved memory. The original report remained unchanged.

The app retains the actual reports, accepted guidance, stage counts, session IDs, retrieved excerpts and graph. Runtime artifacts remain local and excluded from Git; Cloud memory lives in the configured tenant.

## What this establishes

The run demonstrates multi-source research, cross-agent memory retrieval, native memory consolidation, and durable guidance retrieved by a new session. It does not establish model-weight training, a general accuracy gain, commercial partner eligibility, or the existence of a live government solicitation.

## Two-minute judging walkthrough

1. Open Research team and select the completed run.
2. Inspect the 29-source collection: 28 external documents plus its internal brief.
3. Open the partner/reviewer reports and their retrieved-memory disclosures.
4. Inspect the accepted review lesson and the preserved original report.
5. Show the four recorded lessons and the fresh-session memory proof.
6. Inspect the actual Cognee memory map and a source link.

To reproduce the computation, start a new research run and accept a genuine new review lesson. The system records zero/no-learning outcomes honestly; it does not force an answer change.
